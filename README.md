# Tour Search App

A client-side tour search service built as a frontend technical assessment.

## Tech Stack

- **React 19** + **Vite** — SPA infrastructure
- **TypeScript** (strict) — full type safety
- **React Router v7** — client-side routing
- **Zustand** — search state machine
- **TanStack Query** — server state caching (hotels, price, hotel detail)
- **Tailwind CSS v4** — styling
- **@floating-ui/react** — accessible dropdown positioning

## Local Setup

```bash
git clone <your-repo-url>
cd tour-search
npm install
```

Place the provided `api.js` file into `src/api/`.

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)
